# tools/ — ინსტაგრამის ექსპორტის დამუშავება

ერთი ექსპორტიდან სამი შედეგი: კლიენტების ბაზა (E7), Copilot-ის სატესტო
ნაკრები (E11) და Brain-ის კანდიდატები.

## გაშვება

```bash
unzip instagram-export.zip -d data/ig-export
python3 tools/run_all.py data/ig-export
```

შედეგები: `data/out/`. **`data/` gitignore-შია** — ჩატები პირადი მონაცემია და
GitHub-ზე არ ადის (იხ. `CLAUDE.md`).

## რას აკეთებს

| ფაილი | რა |
|---|---|
| `ig_export.py` | ექსპორტის კითხვა. ასწორებს mojibake-ს: Instagram ქართულს latin-1-ად წერს და გაუსწორებლად არაფერი იკითხება |
| `signals.py` | ქართული სიგნალები: ტელეფონი, ზომა, შეკვეთის ეტაპი, გაუქმების მიზეზი |
| `e7_clients.py` | `data/out/clients.csv` — თითო კლიენტი თითო სტრიქონი |
| `e11_copilot.py` | `data/out/copilot-test-20/` — 20 ჩატი, დახურული/დაკარგული/კითხვა კატეგორიებად |
| `brain_mine.py` | `data/out/brain-candidates.md` — განმეორებადი კითხვები და პასუხები, ცვლადებით |

## ტესტები

```bash
python3 -m unittest discover -s tests
```

სინთეზურ ექსპორტზე მუშაობს (`tests/make_fixture.py`), რეალური მონაცემი
ტესტებში არ დევს.

## რა უნდა გადამოწმდეს რეალურ ექსპორტზე

ეს კოდი ინსტაგრამის სტანდარტულ JSON სტრუქტურაზეა აწყობილი და სინთეზურ
მონაცემზეა შემოწმებული. რეალურ ექსპორტზე პირველ გაშვებაზე გადაამოწმე:

1. `owner` სწორად ამოიცნო? (ბეჭდავს გაშვებისას)
2. `clients.csv`-ში ქართული იკითხება?
3. ჯგუფური ჩატები გამოტოვებულია — თუ იქ გაყიდვები ხდება, `e7_clients.py`
   შესაცვლელია.
4. ეტაპებისა და გაუქმების საკვანძო სიტყვები (`signals.py`) შენს რეალურ
   ლექსიკას ემთხვევა? ეს სია ხელით უნდა გაფართოვდეს.
