## ცნობილი რისკები

- Visual Pipeline: შეყვანა მომწოდებლის ფოტოა (წარმოებული). ქსოვილი/ლოგო/პრინტი მახინჯდება = დაბრუნება.
- Consignment: „შემოწმებულია" წარწერა + ყალბი = შპს-ს პასუხისმგებლობა. ვარიანტები: ხელით ჩეკლისტი + გამყიდველის გარანტია; Entrupy-ს ტიპი ძვირზე.
- Brain: დოკუმენტი არ განახლდა = ბოტი ძველ წესს ამბობს დარწმუნებით. წესი: ჯერ დოკუმენტში, მერე ჩატში.
