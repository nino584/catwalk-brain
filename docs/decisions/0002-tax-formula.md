# ADR 0002: შპს-ს გადასახადის ფორმულა თითო შეკვეთაზე

სტატუსი: ბლოკირებული. ელოდება თათულს.

v2 ფორმულა (ინდმეწარმეზე, აღარ მოქმედებს):
- import_cost = 1.18 × (18% × (cost + 27) + 20), თუ sale_price ≥ 300 ₾
- contribution = margin − import_cost − bonus

საჭირო თათულისგან:
| ფასის დიაპაზონი | გადასახადის ბაზა | მოსალოდნელი ხარჯი შეკვეთაზე |
|---|---|---|
| < 300 ₾ | | |
| 300-1000 ₾ | | |
| > 1000 ₾ | | |

სანამ ეს არ შეივსება, E3 (მარჟის იატაკი), E6 (ტრანზიტული აღრიცხვა), E8 (ბონუსები) არ იწერება.
